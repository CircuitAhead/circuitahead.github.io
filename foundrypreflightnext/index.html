FoundryPreflightNext

Prepare the session before the session starts.

FoundryPreflightNext is a Windows companion utility built around a practical goal: reduce the recurring technical friction that can get in the way of a Foundry VTT session. Profiles, connectivity checks, ZeroTier status, firewall verification, backups and guided preparation are brought into one workflow.

CAPABILITIES

Built around the checks that are easy to forget.

The project brings recurring session-preparation tasks into a clearer sequence, helping both the person hosting the game and the players joining it.

01

Multi-profile setup

Keep reusable Master and Player configurations separated instead of rebuilding the same setup every time.

02

ZeroTier checks

Verify the service and network state used to reach a Foundry host when direct connectivity is not available.

03

Firewall verification

Check the Windows firewall configuration used by the Foundry connection workflow, including the TCP 30000 rule.

04

Master backups

Support recurring world-backup operations before changes or sessions, keeping preparation close to the rest of the workflow.

05

Player backup tools

Give players a simpler path to preserve supported character data without turning backup into a separate technical procedure.

06

Guided Session

Turn preparation into a sequence of checks and actions so the user can move from setup to session with less guesswork.

TWO SIDES OF THE SAME SESSION

Different needs for Master and Player.

FoundryPreflightNext does not treat every user the same. The preparation flow changes according to the role and keeps the relevant tools close at hand.

MASTER

Host with fewer moving parts.

The Master side focuses on the tasks that matter before opening the table to players: world protection, Foundry readiness, network state and connection prerequisites.

  • Reusable Master profile
  • World backup workflow
  • Firewall and connectivity verification
  • Persistent player connection information
PLAYER

Join without rebuilding the setup.

The Player side reduces the amount of technical information a player needs to manage, preserving the connection flow and supported local backup actions in a simpler interface.

  • Reusable Player profile
  • Persistent session link
  • ZeroTier readiness checks
  • Supported character backup workflow

DESIGN APPROACH

A companion tool, not another platform.

FoundryPreflightNext is designed to coordinate preparation around tools that already exist. It does not replace Foundry VTT or ZeroTier; it helps make the repeated setup around them more understandable and repeatable.

Local Windows workflow

The utility is built around the user's own PC and the software involved in the session setup.

Repeatable checks

Recurring preparation is turned into a recognizable sequence instead of relying on memory every time.

Role-aware experience

Master and Player receive different tools because they have different responsibilities before a session.

Designed for troubleshooting

When something does not work, the utility aims to surface the relevant checks instead of leaving the user to search through Windows settings manually.
